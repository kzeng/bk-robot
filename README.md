
## 目标
- 实现图书馆机器人自动智能视觉图书盘点
- 智能视觉图书盘点机器人有以下及部分组成
    - 硬件
        - 机器人底座 [控制接口](./docs/WATER_API.pdf)
        - 工控机  
        - 显示屏幕*
        - 摄像头模组
        - 升降柱
    - 软件
        - 采用国产银河麒麟或者OpenKylin系统
        - 控制算法
        - 任务管理
        - 任务日志管理
        - 数据管理
        - 用户认证
        - 系统设置

## 技术栈
- Linux
- Python 
- Flask
- OpenCV/OBS
