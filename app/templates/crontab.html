计划任务管理

格式
* * * * *  命令
| | | | |
| | | | +--- 星期（0-6，0表示星期天）
| | | +----- 月（1-12）
| | +------- 日（1-31）
| +--------- 小时（0-23）
+----------- 分钟（0-59）
  • 每行 crontab 条目由 6 个字段组成：
  • 每个字段可以用数字、范围（例如 1-5）、列表（例如 1,3,5）或 *（表示任意值）来定义。
  • 后面的“命令”是要执行的脚本或命令。
示例
  1. 每天凌晨 2:30 执行备份脚本： 
    30 2 * * * /bin/bash /home/user/backup.sh
  2. 每小时的第 0 分钟运行检查程序： 
    0 * * * * /usr/bin/check_status
